## مراحل بعدی
1. `git stash drop` (بپاکن کشایی با HEAD یکی است → اضافی است).
2. `git push --force origin dev` و `git push --force origin main` (ریپوی خصوصی خود کاربر؛ Force لازم چون replaced history).
3. پاکسازی مدارک محلی: `git for-each-ref -d refs/original`, `git reflog expire --expire=now --all`, `git gc --prune=now`.
4. راستی‌آزمایی نهایی: جستجو در همه refها + `gh api` آخرین commit روی ریپو.
5. گزارش محدودیت‌ها: کش Git/Actions گیت‌هاب قابل حذف نيست (پاسخ ادمین)؛ گیرنده‌های قدیمی ریپو، اگر نگه داشته باشند، تاریخچه قدیمی دارند. این محدودیت‌ها گزارش تا کاربر تصمیم بگیرد (مثلاً ساخت ریپوی تازه).

## مخاطرات
- Force-push = بازنویسی عمومی ریپوی خصوصی کاربر (مجوز صریح از کاربر).
- کش‌های Actions روی گیت‌هاب درخت‌های قدیمی را نگه می‌دارند.
- فایل‌های پچ‌شده سرور (`62.220.127.238`) در سورس می‌مانند — کاربر فقط خواستار حذف تاریخچهٔ sync-ctx بود.
